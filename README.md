## 🧠 Overview

**NULLTRACE** Is A Python-First **Incident Intelligence Platform** That Transforms Raw Telemetry Into Actionable Insights.

It Connects To Real-World Observability Platforms Like:

- Datadog  
- Grafana  
- New Relic  

Then:

- 🔄 Normalizes Logs, Alerts, Metrics, Traces  
- 🧩 Builds A Unified **Incident Graph**  
- 🎯 Ranks Probable Root Causes  
- 📋 Generates Evidence-Based Next Steps  

> ⚠️ No Fake Data. No Simulations. No Mock Incidents.  
> The System Starts Empty — **Real Signals Only.**

## 🤖 Ai Integration (OpenRouter)

Enable Ai-Powered Analysis By Setting:

```env
OPENROUTER_API_KEY=your_api_key
```

### 🔐 Security Model
- Api Key Is **Server-Side Only**  
- Never Exposed To Browser  
- Safe By Design  

### 🧠 Default Model

```text
deepseek/deepseek-v4-flash:free
```

### 🔄 Fallback Model

```text
liquid/lfm-2.5-1.2b-instruct:free
```

> Automatically Switches If Provider Is Unavailable.
